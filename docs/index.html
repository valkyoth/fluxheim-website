Fluxheim Documentation

Fluxheim is a memory-safe edge server built on Cloudflare's Pingora framework. These docs cover installation, configuration, all features, and deployment.

What Fluxheim Does Today

Static website hosting with MIME detection, ETag, conditional 304, and byte ranges
Vhost routing by Host header with default-vhost fallback and strict host routing
Whole-vhost and route-level reverse proxying with upstream pool support
Admin control-plane with bearer-token auth and loopback defaults
rustls TLS with multi-cert SNI, static/bought certificates
Managed ACME with HTTP-01 and TLS-ALPN-01 issuance and renewal
Route-scoped cache: memory, disk, tiered, encrypted, distributed peer fill
Prometheus metrics and OpenTelemetry metrics/tracing export profiles
PHP-FPM FastCGI bridge for WordPress-style front-controller apps
Rootless Podman containers: Wolfi, Alpine, SUSE Micro, Debian
