Fluxheim Docs Feature Matrix

Feature Matrix

All Cargo features, build profile aliases, and TLS backend options for Fluxheim v1.5.14.

Individual Features

Select features individually with --features or use profile aliases (below). TLS backends are mutually exclusive — pick exactly one.

Feature Default Description
proxy Fluxheim reverse proxy runtime and admin plumbing.
web Static file resolver. Runtime currently uses proxy sessions.
cache Cache module compiled in. Runtime cache remains disabled until configured.
compression — Shared response compression framework. Requires at least one codec feature.
compression-gzip — gzip response compression codec with MIME, size, privacy, range, and cache-safety guards.
compression-zstd — Zstandard response compression codec, negotiated after Brotli and before gzip when enabled.
compression-brotli — Brotli response compression codec and first-preference encoding when clients advertise it.
ingress via proxy/TLS Shared Rust/Tokio ingress primitives used by proxy, TLS, and ACME-capable focused builds.
security Compile-time security profile marker plus release hardening checks. Runtime enforcement lives in concrete config, TLS, filesystem, admin, and request-handling modules.
tls-rustls rustls TLS backend (default and recommended). Mutually exclusive with other TLS features.
tls-rustls-backend — Internal rustls backend marker shared by ring-backed rustls and the AWS-LC FIPS-capable candidate path.
tls-rustls-fips — Optional rustls/AWS-LC FIPS-capable TLS backend candidate.
tls-rustls-iso19790 — ISO/IEC 19790 terminology alias for tls-rustls-fips.
tls — Internal TLS-aware code marker. Select exactly one concrete backend for serving.
load-balancer — Fluxheim load-balancer control plane with advanced selection, health, persistence, runtime member controls, and focused 1.5 image profile support.
traffic-mirror — Opt-in bodyless request shadowing for safe traffic mirroring. Implies proxy.
geoip — Local MMDB Geo-Context lookup for MaxMind GeoIP2/GeoLite2 and CIRCL Geo Open datasets. Exposes bounded country/ASN policy and access-log fields. Implies proxy.
stream-proxy — Raw L4 TCP stream proxy service with separate [stream] routes, bounded idle/lifetime/byte caps, route-local PROXY protocol receive/send, upstream TLS/mTLS controls, and weighted/drain/backup policy.
metrics — Prometheus metrics listener.
metrics-otlp — Optional local OTLP metrics export.
otel-tracing — OpenTelemetry trace context propagation.
otel-otlp — Optional local OTLP trace export.
acme — ACME config, storage, challenge serving, renewal planning, and renewal-executor contract.
acme-client — Live ACME account/order HTTP client and background renewal service for HTTP-01 and TLS-ALPN-01.
php — Shared PHP runtime marker. Implies proxy and web.
php-fpm — PHP-FPM FastCGI bridge for WordPress-style PHP applications. Implies proxy and web.
privacy-mode — Zero-retention static/proxy profile. Incompatible with cache, compression, metrics, and tracing/export features.
tls-openssl — Optional OpenSSL TLS backend. Mutually exclusive with other TLS features.
tls-openssl-fips — OpenSSL 3 FIPS-provider proof path with provider diagnostics and fail-closed FIPS/ISO-required startup checks.
tls-openssl-iso19790 — ISO/IEC 19790 terminology alias for tls-openssl-fips.

Fluxheim 1.5.4 removed the incomplete BoringSSL and s2n backend integrations. The supported TLS backend matrix is rustls, rustls/AWS-LC FIPS-capable candidate builds, OpenSSL, and OpenSSL FIPS/ISO proof builds.

Build Profile Aliases

Profile aliases are normal Cargo feature aliases that enable a curated set of features. Use --no-default-features --features <profile> to build a focused image. The raw aliases do not force acme-client; official release artifacts add it where managed certificates are expected.

profile-static-siteproxy, web, tls-rustls, securityStatic sites without cache

profile-cache-serverproxy, web, cache, tls-rustls, securityStatic/proxy server with cache enabled
profile-cache-edgeproxy, cache, compression-gzip, compression-zstd, compression-brotli, tls-rustls, securityCache edge without local static web serving
profile-proxy-edgeproxy, compression-gzip, compression-zstd, compression-brotli, tls-rustls, securityFocused reverse proxy edge
profile-load-balancerproxy, web, cache, compression-gzip, compression-zstd, compression-brotli, load-balancer, tls-rustls, securityProduction proxy/load-balancer bundle with compression enabled
profile-load-balancer-edgeproxy, load-balancer, compression-gzip, compression-zstd, compression-brotli, tls-rustls, securityLoad-balancer edge without cache or static web
profile-observabilityprofile-core + metrics, metrics-otlp, otel-tracing, otel-otlpCore with full observability stack
profile-privacyproxy, web, tls-rustls, privacy-mode, securityZero-retention static/proxy profile

profile-fullprofile-load-balancer, traffic-mirror, geoip, stream-proxyAll stable production modules, including safe traffic mirroring, bounded Geo-Context, and hardened stream proxying

Official Release Builds

The release artifacts match specific feature sets. Custom source builds can omit acme-client for offline or static-certificate deployments.

bash — official release build commands
# Full release build (matches fluxheim-1.5.14-full-*.tar.gz)
cargo build --release --no-default-features \
  --features profile-full,acme-client,metrics,metrics-otlp,otel-tracing,otel-otlp

# Cache edge build (matches fluxheim-1.5.14-cache-*.tar.gz)
cargo build --release --no-default-features \
  --features profile-cache-edge,acme-client

# Proxy edge build (matches fluxheim-1.5.14-proxy-*.tar.gz)
cargo build --release --no-default-features \
  --features profile-proxy-edge,acme-client

# Load-balancer edge build (matches fluxheim-1.5.14-load-balancer-*.tar.gz)
cargo build --release --no-default-features \
  --features profile-load-balancer-edge,acme-client

# PHP-FPM build (matches fluxheim-1.5.14-php-*.tar.gz)
cargo build --release --no-default-features \
  --features profile-web-server,php-fpm,acme-client

# Config tester diagnostic artifact
cargo build --release --no-default-features \
  --features profile-development \
  --bin fluxheim-config-tester

Cache Encryption Key Utility

fluxheim cache-keygen is available in every build profile. It prints one random 256-bit lowercase hex key suitable for [cache.disk.encryption] provider = "local". The command does not write files; pipe it into your secret manager, systemd credential source, or container secret workflow.

bash — local cache encryption key
fluxheim cache-keygen

Feature Validation

Use scripts/validate-features.sh before packaging custom feature strings. The validator expands profile aliases and rejects unsupported combinations before Cargo starts compiling Fluxheim.

bash — feature validation
scripts/validate-features.sh proxy,web,tls-rustls
scripts/validate-features.sh profile-privacy

Privacy Build Constraints

The privacy-mode feature is incompatible with cache, compression, compression-gzip, compression-zstd, compression-brotli, geoip, metrics, metrics-otlp, otel-tracing, and otel-otlp at compile time. Always use --no-default-features with profile-privacy, since the default build includes cache.

bash — privacy builds
# Zero-retention privacy build
cargo build --release --no-default-features \
  --features profile-privacy

# Validate custom feature combination before building
scripts/validate-features.sh proxy,web,tls-rustls,privacy-mode
