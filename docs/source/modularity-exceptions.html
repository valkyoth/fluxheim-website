Fluxheim Modularity Exceptions

Status: baseline inventory for the 1.6 line

This file records legacy non-generated Rust files above the 500-line target in Fluxheim Modularity Policy. The 1.6 line should shrink this list as Pingora adapters, root orchestration, config, cache, admin, and proxy code move into focused workspace crates.

New or newly split files should not be added here unless the same release documents why the exception is temporary and how it will be removed.
