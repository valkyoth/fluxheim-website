Fluxheim Docs Cache System

Cache System

Fluxheim's cache system supports memory, disk, tiered, and encrypted backends with route-scoped policies, cache locks, stale serving, distributed peer fill, and range caching.

Enabling Cache

The cache Cargo feature must be compiled in (default in pre-built binaries). Runtime cache is disabled until configured per-vhost.

fluxheim.toml — basic memory cache
[[vhosts]]
name = "site"
hosts = ["example.com"]

[vhosts.cache]
enabled = true
status_ttls = { "200" = 300 }
stale_while_revalidate_secs = 30

[vhosts.cache.memory]
enabled = true
max_size_bytes = "512MiB"

[vhosts.cache.lock]
enabled = true

Cache Backends

Memory Cache

Fast in-process LRU cache. Lost on restart. Best for frequently accessed small-to-medium objects.

toml
[vhosts.cache]
enabled = true

[vhosts.cache.memory]
enabled = true
max_size_bytes = "256MiB"

Disk Cache

Persistent on-disk cache. Survives restarts. The storage-bin backend (v1.2.2+) is optimised for larger, high-churn caches.

toml
[vhosts.cache]
enabled = true

[vhosts.cache.disk]
enabled = true
path = "/var/cache/fluxheim/site"
max_size_bytes = "10GiB"
backend = "storage-bin"

Tiered Cache

Hot memory tier backed by disk. Objects are promoted to memory on repeated access and written through to disk for persistence.

toml
[vhosts.cache]
enabled = true

[vhosts.cache.memory]
enabled = true
max_size_bytes = "256MiB"

[vhosts.cache.disk]
enabled = true
path = "/var/cache/fluxheim/site"
max_size_bytes = "20GiB"

Encrypted Disk Cache

Available since v1.2.3. Cache objects are encrypted at rest using a local key or an OpenBao Transit engine.

toml
[vhosts.cache]
enabled = true

[vhosts.cache.disk]
enabled = true
path = "/var/cache/fluxheim/site"

[vhosts.cache.disk.encryption]
enabled = true
# Local key file
key_file = "/etc/fluxheim/cache.key"
key_id = "cache-v1"
# Or: OpenBao Transit
# provider = "openbao-transit"
#
# [vhosts.cache.disk.encryption.openbao]
# address = "https://openbao.internal.example"
# mount = "transit"
# key_name = "fluxheim-cache"
# token_credential = "openbao-token"

Cache Policies

Cache Lock (Stampede Prevention)

With [vhosts.cache.lock].enabled = true, only one upstream request is made per cache key when a miss occurs. Other requests wait for the fill to complete and are served from cache.

Stale While Revalidate

With stale_while_revalidate_secs, expired cache entries are served immediately while a background request fills the cache with fresh content. Eliminates tail latency on cache expiry.

Distributed Peer Fill

Available since v1.2.4. When a request misses the local cache, Fluxheim can fetch from a cache peer before going to the upstream origin. Uses a safe only-if-cached semantics — if the peer doesn't have it, the request falls through to the origin.

toml
[vhosts.cache]
enabled = true

[vhosts.cache.disk]
enabled = true
path = "/var/cache/fluxheim/site"

[vhosts.cache.peer_fill]
enabled = true
connect_timeout_secs = 2
read_timeout_secs = 10
max_concurrent_requests = 64
fail_open = true

[[vhosts.cache.peer_fill.peers]]
name = "edge-a"
base_url = "https://cache-peer-1.internal:9100"

[[vhosts.cache.peer_fill.peers]]
name = "edge-b"
base_url = "https://cache-peer-2.internal:9100"

Range Caching

Available since v1.2.5. Opt-in bounded range caching for large proxy-cache objects — useful for large media files and binary downloads.

Fixed-Slice Range Cache (v1.2.6+)

Extended range-cache mode that supports open-ended, suffix, and multipart byte-range responses by composing cached fixed-size slices.

toml
[vhosts.cache]
enabled = true
max_object_bytes = "32MiB"

[vhosts.cache.disk]
enabled = true
path = "/var/cache/fluxheim/site"

[vhosts.cache.range]
enabled = true
max_bytes = "128MiB"

[vhosts.cache.range.slice]
enabled = true
size_bytes = "1MiB"
max_slices = 128
fill_missing = true

Cache Operations

Fluxheim exposes protected cache status and purge endpoints through the admin API. Warming and key inspection are CLI operations.

bash — admin API cache operations
# Inspect aggregate cache status
curl http://127.0.0.1:9090/_fluxheim/cache/status \
  -H "Authorization: Bearer $ADMIN_TOKEN"

# Purge a specific cache identity
curl -X POST "http://127.0.0.1:9090/_fluxheim/cache/purge?host=example.com&path=/css/main.css" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \

# Preview the selected cache key without contacting origin
fluxheim --config /etc/fluxheim/fluxheim.toml cache-key \
  --host example.com --path /css/main.css

# Warm through a running local listener
fluxheim --config /etc/fluxheim/fluxheim.toml cache-warm \
  --host example.com --path /css/main.css

Local Static-File Caching

Opt-in since v1.2.1. When local_static = true is enabled on the cache policy, Fluxheim caches static files from the local filesystem through the cache layer for hot-path performance.

toml
[vhosts.web]
root = "/srv/sites/example/public"
index_files = ["index.html"]
[vhosts.cache]
enabled = true
local_static = true

[vhosts.cache.memory]
enabled = true
max_size_bytes = "128MiB"

Privacy builds: The cache feature is compile-time incompatible with privacy-mode. Zero-retention deployments must use --no-default-features with profile-privacy to ensure no caching occurs.
