Fluxheim Docs Config Reference

Config Reference

Fluxheim is configured via a single TOML file. Use --check-config to validate before restarting.

Full Example

/etc/fluxheim/fluxheim.toml
[server]
listen = ["0.0.0.0:80"]
tls_listen = ["0.0.0.0:443"]
default_vhost = "site"

[admin]
enabled = true
listen = "127.0.0.1:9090"
require_loopback = true
token_file = "/run/secrets/fluxheim-admin-token"

[headers.response]
enabled = true
x_content_type_options = "nosniff"
x_frame_options = "DENY"
referrer_policy = "no-referrer"

[tls.acme]
enabled = true
storage = "/var/lib/fluxheim/acme"
contact_email = "admin@example.com"
default_issuer = "letsencrypt"

[[vhosts]]
name = "site"
hosts = ["example.com", "www.example.com"]

[vhosts.tls]
enabled = true

[vhosts.tls.acme]
enabled = true

[vhosts.web]
root = "/srv/sites/example/public"
index_files = ["index.html"]
deny_dotfiles = true
cache_control = "public, max-age=3600"

[[vhosts.routes]]
name = "api"
path_prefix = "/api"
[vhosts.routes.proxy]
upstreams = ["127.0.0.1:3000"]

[[vhosts.routes]]
name = "old"
path_prefix = "/old"
[vhosts.routes.redirect]
to = "/new"
status = 301

[vhosts.cache]
enabled = true

[vhosts.cache.memory]
enabled = true
max_size_bytes = "256MiB"

[server]

KeyTypeDefaultDescription
listenstring[]["127.0.0.1:8080"]Cleartext listener addresses. Each entry is host:port.
tls_listenstring[][]Explicit TLS listener addresses. Fluxheim does not infer TLS from port numbers.
default_vhoststring—Name of the vhost to use when no Host header matches. Required.
trusted_proxiesstring[][]Trusted direct peers for recursive client-IP restoration.
[server.https_redirect].enabledboolfalseEnable global HTTP to HTTPS redirect with safe Host validation.
[server.host_routing].strictboolfalseReject missing, invalid, or unknown host identity instead of falling back to the default vhost.
[server.limits].max_request_body_bytesstring"16MiB"Maximum request body size.
[server.process].threadsinteger1Runtime worker thread count. Process settings require a process upgrade.

[admin]

The admin control-plane provides health, status, purge, and config-reload endpoints. It requires bearer-token authentication on non-loopback listeners.

KeyTypeDefaultDescription
enabledboolfalseEnable the admin listener.
listenstring"127.0.0.1:9090"Admin listener address. Keep loopback where possible.
require_loopbackbooltrueRequire the admin listener to stay loopback-only.
token_envstring—Environment variable containing the bearer token.
token_filestring—File containing the bearer token. Prefer container or systemd secrets.
[admin.transport].modestring"local_only"Use trusted_tls_terminator only when a trusted local sidecar terminates TLS/mTLS.

[headers.response]

KeyTypeDefaultDescription
enabledbooltrueEnable the secure response header policy.
removestring[][]Headers to remove. Use ["server"] to suppress the default server banner.
[headers.response.add]table—Headers to add or set, such as cache-control.
x_content_type_optionsstring"nosniff"Sets X-Content-Type-Options.
x_frame_optionsstring—DENY, SAMEORIGIN, or unset.
referrer_policystring—Sets Referrer-Policy.
strict_transport_securitystring—Sets Strict-Transport-Security. Only set when TLS is in use.
content_security_policystring—Sets Content-Security-Policy.

[geoip]

When Fluxheim is built with the optional geoip feature, it can load local MMDB databases and expose bounded country/ASN context to route policy and structured logs. GeoIP is local-only: Fluxheim does not download, poll, or refresh databases itself.

fluxheim.toml
[geoip]
enabled = true
fallback_enabled = true

[[geoip.databases]]
provider = "maxmind"
path = "/var/lib/fluxheim/geoip/GeoLite2-Country.mmdb"

[[geoip.databases]]
provider = "circl"
path = "/var/lib/fluxheim/geoip/circl-country.mmdb"
KeyTypeDefaultDescription
enabledboolfalseEnable local Geo-Context lookup when the binary includes geoip.
fallback_enabledboolfalseTry later local MMDB files when the primary file has no usable country or ASN result.
[[geoip.databases]].providerstring—maxmind or circl.
[[geoip.databases]].pathstring—Absolute path to a local MMDB file. Files are bounded at load time.

Route policy can use geo_allow_countries, geo_deny_countries, geo_allow_asns, and geo_deny_asns. Allow lists fail closed when no Geo-Context is available; deny lists only deny on a known match. privacy-mode and geoip cannot be compiled together.

[stream]

When Fluxheim is built with the optional stream-proxy feature, [stream] exposes raw L4 TCP services that stay separate from HTTP routing, headers, cache, compression, auth subrequests, PHP, and static web serving.

fluxheim.toml
[stream]
enabled = true

[[stream.routes]]
name = "postgres"
listen = ["127.0.0.1:15432"]
upstreams = ["10.0.0.11:5432", "10.0.0.12:5432"]
# upstream_weights = [1, 2]
# upstream_aliases = ["pg-a", "pg-b"]
# backup_upstreams = []
# drain_upstreams = []
connect_timeout_secs = 5
idle_timeout_secs = 300
# max_connection_secs = 3600
max_connection_bytes = 1073741824
max_connections = 1024
downstream_proxy_protocol = "off" # "off", "v1", or "v2"
trusted_proxies = []
upstream_proxy_protocol = "off" # "off", "v1", or "v2"
upstream_tls = false
# upstream_sni = "db.internal.example"
# upstream_verify_cert = true
# upstream_verify_hostname = true
# upstream_alternative_cn = "db-alt.internal.example"
# upstream_ca_path = "/etc/fluxheim/upstreams/db-ca.pem"
# upstream_client_cert_path = "/etc/fluxheim/upstreams/client-chain.pem"
# upstream_client_key_path = "/etc/fluxheim/upstreams/client-key.pem"
KeyTypeDefaultDescription
enabledboolfalseEnable dedicated TCP stream listeners when the binary includes stream-proxy.
[[stream.routes]].listenstring[]—One or more ip:port TCP listeners. Each listener may belong to only one stream route.
[[stream.routes]].upstreamsstring[]—One or more host:port upstreams. Multiple upstreams use weighted selection when weights are configured.
upstream_weightsinteger[]—Optional per-upstream weights for stream-local TCP selection.
upstream_aliasesstring[]—Optional safe labels for stream upstreams in logs and metrics.
backup_upstreamsstring[][]Backup upstreams attempted when primary stream upstream connection attempts fail.
drain_upstreamsstring[][]Upstreams excluded from new stream selections while existing connections drain.
idle_timeout_secsinteger300True idle timeout that resets when either direction transfers bytes.
max_connection_secsinteger—Optional wall-clock lifetime cap for one accepted stream connection.
max_connection_bytesinteger—Optional copied-byte cap per direction for a single stream connection.
max_connectionsinteger0Per-route concurrent connection cap. Zero means unlimited.
downstream_proxy_protocolstring"off"off, v1, or v2 receive for this stream route only. Requires route-local trusted proxies.
upstream_proxy_protocolstring"off"off, v1, or v2 send to upstream before forwarding stream bytes.
upstream_tlsboolfalseEnable TLS for stream upstream connections. Cannot be combined with upstream PROXY protocol in this release.
upstream_snistring—Optional RFC 6066-safe SNI name for stream upstream TLS.
upstream_verify_certbooltrueVerify the upstream certificate chain when stream upstream TLS is enabled.
upstream_verify_hostnamebooltrueVerify upstream TLS hostname identity using SNI or the upstream host.
upstream_alternative_cnstring—One alternative certificate name accepted for stream upstream TLS.
upstream_ca_pathpath—Route-local CA bundle for stream upstream TLS verification.
upstream_client_cert_pathpath—Client certificate chain for stream upstream mTLS.
upstream_client_key_pathpath—Client private key for stream upstream mTLS. Temporary key bytes are zeroized after parsing.

With metrics compiled and enabled, stream proxying exports bounded connection outcome and per-direction byte counters. Stream routes do not support UDP, TLS passthrough SNI routing, HTTP policy, HTTP header/body mutation, or Wasm/Lua filters in this release. Stream upstream_tls and upstream_proxy_protocol cannot be combined.

[[vhosts]]

Each vhost is a [[vhosts]] table in TOML (array of tables). They are matched by the Host header.

KeyTypeDescription
namestringUnique identifier for this vhost. Used in logs and as the default_vhost reference.
hostsstring[]List of Host header values that route to this vhost. Wildcard hosts are accepted for matching; managed ACME derives exact domains only unless configured.

[vhosts.web]

KeyTypeDescription
rootstringAbsolute path to the document root directory.
index_filesstring[]List of filenames to serve as directory index. E.g. ["index.html"].
deny_dotfilesboolDeny requests for files or directories starting with ..
cache_controlstringValue for the Cache-Control response header.

[vhosts.tls]

KeyTypeDescription
enabledboolEnable TLS for this vhost. Requires a static certificate, managed ACME source, or global listener certificate.
[vhosts.tls.acme].enabledboolEnable managed ACME certificate issuance and renewal for this vhost.
[vhosts.tls.acme].issuerstringACME issuer to use. Defaults to tls.acme.default_issuer.
[vhosts.tls.acme].domainsstring[]Optional exact SAN names. If omitted, exact vhost hosts are used.
[vhosts.tls.certificate].cert_pathstringPath to PEM certificate file for static/bought certs.
[vhosts.tls.certificate].key_pathstringPath to PEM private key file.

[[vhosts.routes]]

Routes are matched in order. The first matching route wins.

KeyTypeDescription
namestringUnique route name within the vhost. Used in cache scope and logs.
path_exactstringExact URL path matcher. Use one matcher only.
path_prefixstringURL path prefix matcher. Use one matcher only.
fallbackboolFallback matcher when no earlier route matched. Use one matcher only.
[vhosts.routes.proxy]tableProxy action. Use upstreams = ["127.0.0.1:3000"] for one or more origins.
[vhosts.routes.web]tableRoute-scoped static web action.
[vhosts.routes.redirect]tableRedirect action with to and optional status 301, 302, 307, or 308.
[vhosts.routes.php]tableRoute-scoped PHP action when built with a PHP runtime feature.
geo_allow_countriesstring[]Optional ISO country allow list when built with geoip. Missing Geo-Context fails closed.
geo_deny_countriesstring[]Optional ISO country deny list. Denies only when the lookup has a known match.
geo_allow_asnsinteger[]Optional ASN allow list. Missing Geo-Context fails closed.
geo_deny_asnsinteger[]Optional ASN deny list. Denies only when the lookup has a known match.

[vhosts.cache]

KeyTypeDescription
enabledboolEnable cache for this vhost.
local_staticboolOpt in to caching local static responses as well as proxy responses.
max_object_bytesstringMaximum cacheable object size, e.g. "32MiB".
status_ttlstablePer-status TTLs, e.g. { "200" = 3600, "404" = 60 }.
[vhosts.cache.memory].enabledboolEnable memory cache tier.
[vhosts.cache.disk].enabledboolEnable disk cache tier. Requires path.
[vhosts.cache.lock].enabledboolEnable request collapsing for concurrent misses on the same cache key.

Gateway Recipes

Multi-vhost with shared TLS

fluxheim.toml
[server]
listen = ["0.0.0.0:80"]
tls_listen = ["0.0.0.0:443"]
default_vhost = "main"

[server.https_redirect]
enabled = true

[tls.acme]
enabled = true
storage = "/var/lib/fluxheim/acme"
contact_email = "admin@example.com"

[[vhosts]]
name = "main"
hosts = ["example.com", "www.example.com"]
[vhosts.tls]
enabled = true
[vhosts.tls.acme]
enabled = true
[vhosts.web]
root = "/srv/sites/main/public"

[[vhosts]]
name = "api"
hosts = ["api.example.com"]
[vhosts.tls]
enabled = true
[vhosts.tls.acme]
enabled = true
[[vhosts.routes]]
name = "api"
path_prefix = "/"
[vhosts.routes.proxy]
upstreams = ["127.0.0.1:4000"]

WordPress with PHP-FPM

fluxheim.toml (requires php-fpm feature)
[[vhosts]]
name = "wordpress"
hosts = ["blog.example.com"]

[vhosts.tls]
enabled = true

[vhosts.web]
root = "/srv/sites/wordpress"
index_files = ["index.php", "index.html"]
deny_dotfiles = true

[vhosts.php]
enabled = true
runtime = "php-fpm"
root = "/srv/sites/wordpress"
index = "index.php"
allowed_extensions = ["php"]

[vhosts.php.fpm]
socket = "/run/php/php8.2-fpm.sock"
