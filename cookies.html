Cookie Notice

Last updated: June 23, 2026

No analytics cookies

The Fluxheim website does not use analytics cookies, advertising cookies, fingerprinting, local storage identifiers, or third-party analytics scripts.

The language selector uses normal links and does not need a cookie. If a future deployment adds a strictly necessary cookie, this notice must be updated before that change is enabled.

Aggregate observability

We collect first-party aggregate observability events to count visits, language usage, page sections, downloads, GitHub redirects, request latency, and approximate visible time on a page.

These events do not contain raw IP addresses, user identifiers, cookie values, browser fingerprints, request bodies, authorization headers, or full query strings.
