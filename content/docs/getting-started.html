Install

Verify the published SHA-256 checksum before extracting an archive.

Linux x86_64

VERSION="1.8.3"
ARCHIVE="fluxheim-${VERSION}-full-x86_64-linux.tar.gz"
BASE_URL="https://github.com/valkyoth/fluxheim/releases/download/v${VERSION}"
curl -fLO "${BASE_URL}/${ARCHIVE}"
echo "faaa006fd2df31d43db69919bdcd79a4abd5f3b6c1f2928525bdaa56e8b83523  ${ARCHIVE}" | sha256sum -c -
tar -xzf "$ARCHIVE"
sudo install -m 0755 "fluxheim-${VERSION}-full-x86_64-linux/fluxheim" /usr/local/bin/fluxheim

macOS Apple Silicon

VERSION="1.8.3"
ARCHIVE="fluxheim-${VERSION}-full-aarch64-macos.tar.gz"
BASE_URL="https://github.com/valkyoth/fluxheim/releases/download/v${VERSION}"
curl -fLO "${BASE_URL}/${ARCHIVE}"
echo "e5cd2245932bfb1727d9deb4dc3df4b117f16eddff899c9579018d3d130a3d65  ${ARCHIVE}" | shasum -a 256 -c -
tar -xzf "$ARCHIVE"
install -d "$HOME/.local/bin"
install -m 0755 "fluxheim-${VERSION}-full-aarch64-macos/fluxheim" "$HOME/.local/bin/fluxheim"

This is an unsigned command-line preview. Keep Gatekeeper enabled; Developer ID signing, notarisation, and launchd integration are not yet provided.

Windows x86_64

$Version = "1.8.3"
$Archive = "fluxheim-$Version-full-x86_64-windows.zip"
$BaseUrl = "https://github.com/valkyoth/fluxheim/releases/download/v$Version"
Invoke-WebRequest "$BaseUrl/$Archive" -OutFile $Archive
$Expected = "c55ced880957062debf3870387c295f149b24ae9cb9512c4655d804dd3bb55f2"
if ((Get-FileHash $Archive -Algorithm SHA256).Hash.ToLowerInvariant() -cne $Expected) { throw "Archive checksum verification failed" }
Expand-Archive -LiteralPath $Archive -DestinationPath "$env:LOCALAPPDATA\Fluxheim" -Force

This is an unsigned portable preview. Keep SmartScreen and PowerShell security enabled; Authenticode signing and a Windows service installer are not yet provided.

Managed PHP-FPM supervision is Unix-only; Windows supports external TCP FastCGI pools.

Minimal static site

[server]
listen = ["0.0.0.0:8080"]
default_vhost = "site"

[[vhosts]]
name = "site"
hosts = ["example.com"]

[vhosts.web]
root = "/srv/example"
index_files = ["index.html"]
deny_dotfiles = true

What the first config does

OptionPurpose
server.listenControls the plain HTTP socket Fluxheim opens.
server.default_vhostSelects the fallback site when no host matches.
vhosts.hostsLists the hostnames accepted by the site.
vhosts.web.rootPoints at the directory served to visitors.

Check and start

fluxheim --config /etc/fluxheim/fluxheim.toml --check-config
fluxheim --config /etc/fluxheim/fluxheim.toml

Use the config check in deployment scripts. It catches unknown fields, unsafe paths, invalid listeners, and feature/config mismatches before traffic moves.

Next useful choices

  • Add TLS only after DNS points at the host.
  • Add cache only for routes that are safe to share between visitors.
  • Add metrics only when the listener is private or behind a trusted proxy.
