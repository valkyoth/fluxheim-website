WAF

The WAF track is for rule-based request filtering, logging, and challenge/block responses. It should become its own clear page when it is production-ready.

Planned areaExpected use
RulesBlock or challenge suspicious requests before they reach an app.
SignalsRecord bounded security events without storing sensitive payloads.
ExceptionsAllow controlled bypasses for known safe application paths.

WASM extensions

Fluxheim 1.7.5 keeps Wasm optional and extends bounded native HTTP/1 cache-policy hooks alongside access-decision, header, and route-decision hooks. Plugins can continue normal cache behavior, pass through origin, bypass cache, skip storage, deny, select fixed mobile/desktop cache-key variants, and attach fixed cache-store TTL, tag, and stored-header metadata, but they still cannot emit arbitrary cache-key bytes, arbitrary TTLs, arbitrary tags, raw response headers, bodies, filesystem access, network access, private keys, or admin APIs.

RuleReason
Disabled by defaultDefault and privacy builds do not compile Wasm features.
Approved plugin rootsPlugin files must be absolute, regular files below approved roots, without symlinked files or parent paths.
Access decisionsLive native HTTP/1 access-decision hooks use priority ordering, first-deny-wins composition, and fail-closed behaviour.
Header hooksrequest-headers and response-headers hooks can set or remove only allow-listed synthetic headers such as the policy-tier example.
Route decisionsroute-decision hooks can continue, deny, or select only configured matching canary and mirror route branches.
Cache decisionscache-lookup hooks can continue, pass, bypass, or deny. cache-store hooks can continue, skip storage, or deny before memory/disk cache writes.
Cache metadatacache-lookup hooks can add fixed mobile/desktop cache-key variants. cache-store hooks can set fixed TTL, tag, and stored-header metadata.
Bounded executionFuel, memory, table, instance, compile-timeout, compile-worker, and per-call watchdog limits keep the sandbox bounded.
Admission limitsProcess-wide, per-plugin, and per-attachment execution ceilings prevent unbounded plugin work.
Typed manifestsABI, phase, fail-mode, path, and sandbox limits are validated before loading.
PHP-FPM fallbackVhost-level header hooks and fallback response-header cleanup now also apply to PHP-FPM fallback responses.
Selected-route policySelected-route ACLs, rate limits, concurrency limits, body limits, redirects, and header policy still run after a Wasm route decision.
Cache-policy limitsCache hooks use a separate process-wide admission ceiling so hot cache-policy routes cannot starve access, route, or header hooks.
