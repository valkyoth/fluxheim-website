GDPR Information

Last updated: June 23, 2026

Purpose and lawful basis

The purpose of the website telemetry is security, reliability, capacity planning, and aggregate documentation improvement. The intended lawful basis is legitimate interest in operating and securing the website with privacy-minimised telemetry.

Data minimisation

Metrics use bounded labels such as locale, normalized route, section, status class, download artifact, GitHub target, and optional country code. The implementation is designed not to store or export raw IP addresses or user-level tracking identifiers.

GitHub outbound clicks are counted in aggregate before redirecting the browser to GitHub. GitHub then processes the request under GitHub's own terms and privacy policy.

Your rights

Because the website avoids user identifiers and stores only aggregate telemetry, we normally cannot identify a specific visitor inside the metrics. Privacy or GDPR questions can be opened through the Fluxheim GitHub project.
