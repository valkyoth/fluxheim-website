Legal and Privacy

Privacy Policy

Last updated: June 23, 2026

What we collect

The website records aggregate operational metrics: request counts, page views, selected language, normalized page route, section, HTTP status class, request duration, download clicks, GitHub redirect clicks, and approximate page visible time.

Optional country aggregation may be enabled by the operator. When enabled, the server derives a country code in memory and exports only the country code or unknown.

What we do not collect

We do not export raw IP addresses, per-user identifiers, analytics cookies, browser fingerprints, complete user agents, referrer URLs, request bodies, authorization headers, cookie headers, or full query strings.

Telemetry is used to operate the website, understand aggregate documentation and download usage, and detect reliability problems. It is not used to build profiles about individual visitors.

Retention

Retention is controlled by the local Prometheus and Grafana deployment operated for the website. The website application does not write a separate analytics database.
