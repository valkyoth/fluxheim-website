What's Next

1.6.7 moves server bootstrap planning, listener inventory, service intent, background-task intent, HTTP/2 policy, PROXY protocol policy, and private Unix socket planning into Fluxheim-owned server code. Next planning stays on incremental 1.6.x runtime ownership work while arbitrary scripting, production UDP/GSLB, WAF, and VPN/firewall behavior remain future boundaries.
